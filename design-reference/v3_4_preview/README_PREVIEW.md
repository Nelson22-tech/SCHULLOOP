# SchulLoop Preview Pack — v3.4

## What is included
- `index.html`: responsive, navigable visual preview. Open it in Chrome, Edge, Safari or Firefox.
- `SchulLoop_Individual_Preview_Screenshots/`: all 35 supplied individual screen references and original preview boards.
- `SchulLoop_SRS_v3.3.pdf`: the original SRS supplied for this task.
- `SRS_v3.4_UPDATE_NOTES.md`: recommended clarifications and next-release requirements.

## How to use
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Choose a module on the left, search for a screen, then select thumbnails or use Previous/Next.

## Important scope note
Only the SRS and screenshot reference pack were uploaded. The original SchulLoop application source project was not supplied. Therefore this delivery is a visual preview package, not a rebuilt or patched Expo/React Native application. The screens are based on the supplied screenshots; the buttons navigate the preview and do not perform backend actions.

## Source baseline
SRS v3.3 describes the current implementation as an Expo SDK 57 / React Native 0.86 client with an Express/MongoDB backend. It explicitly marks several items as partial or planned. The update notes preserve those statuses rather than claiming they are implemented.
